# 3.Prácticas

## Prácticas de Informática

Las prácticas de informática permiten aprender y mejorar los conocimientos sobre el uso de los ordenadores y sus programas. Durante estas actividades se realizan tareas como crear documentos, utilizar Internet, manejar aplicaciones y aprender programación. Estas prácticas ayudan a desarrollar habilidades digitales útiles para los estudios y el futuro laboral.
