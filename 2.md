# 2.Utilidades

> **Kali Linux** es una distribución basada en Debian diseñada específicamente para auditorías de seguridad, pruebas de penetración (*pentesting*), análisis forense e ingeniería inversa.

---

## 🛠️ Categorías Principales de Herramientas

| Categoría | Propósito Principal | Herramientas Destacadas |
| :--- | :--- | :--- |
| 🔍 **Recopilación de Información** | Reconocimiento pasivo y activo de objetivos. | `Nmap`, `Maltego`, `theHarvester`, `Recon-ng` |
| 🛡️ **Análisis de Vulnerabilidades** | Escaneo de fallos conocidos en sistemas y redes. | `OpenVAS`, `Nikto`, `Nessus` *(externo)*, `Lynis` |
| 🌐 **Aplicaciones Web** | Auditoría de sitios web, APIs y bases de datos. | `Burp Suite`, `OWASP ZAP`, `SQLmap`, `Gobuster` |
| 💥 **Explotación** | Aprovechamiento de fallos para ganar acceso. | `Metasploit Framework`, `SearchSploit`, `BeEF` |
| 🔑 **Ataques de Contraseñas** | Fuerza bruta, diccionarios y *cracking* de hashes. | `John the Ripper`, `Hashcat`, `Hydra`, `Crunch` |
| 📡 **Ataques Wireless** | Auditoría de redes Wi-Fi, Bluetooth y RFID. | `Aircrack-ng`, `Wifite`, `Kismet`, `Bettercap` |
| 🕵️ **Sniffing y Spoofing** | Interceptación de tráfico y suplantación en red. | `Wireshark`, `Ettercap`, `Responder`, `mitmproxy` |
| 🔬 **Análisis Forense** | Recuperación de datos y análisis post-incidente. | `Autopsy`, `Volatility`, `Binwalk`, `Foremost` |

---

## ⚡ Comandos Esenciales (Cheatsheet)

### 1. Escaneo de Red con Nmap
```bash
# Escaneo rápido de puertos abiertos y detección de servicios
nmap -sV -sC -T4 <IP_OBJETIVO>
```

### 2. Búsqueda de Directorios Web con Gobuster
```bash
# Fuerza bruta de rutas en un servidor web
gobuster dir -u http://<IP_OBJETIVO> -w /usr/share/wordlists/dirb/common.txt
```

### 3. Cracking de Contraseñas con John the Ripper
```bash
# Romper hashes usando el famoso diccionario rockyou
john --wordlist=/usr/share/wordlists/rockyou.txt hashes.txt
```

### 4. Framework de Explotación con Metasploit
```bash
# Iniciar la consola principal de Metasploit
msfconsole
```
